% Dumbbell (before->after) replacement for the old §6 line chart (2026-08-17
% chart redesign). Rationale: the old figure had four "lines" spanning only
% two x-positions (R1, R2) that nearly collide at R2 (Market A0 4.966 vs
% CUHK03 A3 4.977) -- that is a before/after comparison wearing line-chart
% grammar, not a trend. A dumbbell says exactly that: one dot per stage, one
% arrow, and the claim ("every arrow points right") is visually unmistakable.
%
% Two panels, one row per dataset x attacker, light dot = R1, dark dot = R2,
% same two navy shades used in the §5 heatmap ramp (navyramp2 / navyramp5 ==
% navy) so the whole poster's numeric charts read as one system. Row order is
% identical in both panels and matches the paper's tab:cuhk_replication order.
%
% LAYOUT (2026-08-17 fix): tabular columns -- row name | R1 value | dumbbell |
% R2 value -- with EVERY item on its own row's baseline (\ry). The previous
% version anchored the value labels at \ry+0.20, which floated each pair into
% the gap between rows so it read against the row ABOVE its own (e.g. CUHK03
% A0's ".226/.399" sat under the "Market A3" row). A fixed left-hand R1 column
% is used instead of an inline label at the left dot because CUHK03 A3's arrow
% is only ~7% of the axis width (4.549->4.977); inline labels at both ends of
% that row would collide. Total picture width is held at ~23 units because the
% figure is placed with \resizebox{0.94\linewidth}{!}{...} -- widening it would
% scale all text down.
%
% Data source: paper tab:cuhk_replication. Cross-checked value-for-value
% against the paper table; see BUILD_NOTES.md. Axis maxima (0.80, 6.6) match
% the old figure's ymax so nothing is renormalized relative to the prior view.
\begin{tikzpicture}
% valW must clear the widest R1 value ("5.198") AND leave a visible gap from the
% row name, otherwise "Market A3" + "5.198" read as one string. axisW is trimmed
% to hold total picture width ~23 units (see \resizebox note above).
\def\rowLabelW{3.0}\def\valW{0.4}\def\rowH{1.05}\def\topPad{1.6}\def\axisW{6.4}

% plot origin (left edge of the value axis) = row-name column + R1-value column
\def\plotX{\rowLabelW+\valW}

% ---- legend (light=R1, dark=R2), once per panel ----
\newcommand{\dlegend}[1]{%
  \draw[fill=navyramp2, draw=navy, line width=0.8pt] ({#1+0.0},{-0.75}) circle (0.09);
  \node[anchor=west, font=\fsSmall\selectfont, color=navy] at ({#1+0.20},{-0.75}) {R1};
  \draw[fill=navyramp5, draw=navy, line width=0.8pt] ({#1+1.55},{-0.75}) circle (0.10);
  \node[anchor=west, font=\fsSmall\selectfont, color=navy] at ({#1+1.76},{-0.75}) {R2};
}

% ---- panel scaffold: #1 xOffset #2 title #3 xmax #4 metric-axis-label #5 tick-list ----
\newcommand{\dpanel}[5]{%
  \node[anchor=north, font=\fsSmall\bfseries\selectfont, color=navy] at (#1+0.5*(\plotX+\axisW),0) {#2};
  \dlegend{#1+\plotX}
  \draw[navy, line width=0.9pt] ({#1+\plotX},{-\topPad-4*\rowH}) -- ++({\axisW},0);
  \foreach \tv in {#5} {
    \pgfmathsetmacro{\tx}{#1+\plotX+(\tv)/(#3)*\axisW}
    \draw[gray!20, line width=0.5pt] (\tx,{-\topPad}) -- (\tx,{-\topPad-4*\rowH});
    \draw[navy, line width=0.7pt] (\tx,{-\topPad-4*\rowH}) -- ++(0,-0.07);
    \node[font=\fsSmall\selectfont, color=navy] at (\tx,{-\topPad-4*\rowH-0.32}) {\tv};
  }
  \node[font=\fsSmall\selectfont, color=navy] at ({#1+\plotX+0.5*\axisW},{-\topPad-4*\rowH-1.02}) {#4};
}

% ---- one dumbbell row: #1 xOffset #2 scale(cm/unit) #3 rowIndex #4 label-line1 #5 label-line2 #6 v1(R1) #7 v2(R2) #8 v1text #9 v2text ----
% Every element below is placed at \ry -- the row's own vertical centre -- so a
% value can never be read against a neighbouring row.
\newcommand{\drow}[9]{%
  \pgfmathsetmacro{\ry}{-\topPad-0.5*\rowH-(#3)*\rowH}
  \pgfmathsetmacro{\rxone}{#1+\plotX+(#6)*(#2)}
  \pgfmathsetmacro{\rxtwo}{#1+\plotX+(#7)*(#2)}
  % column 1: row name, right-aligned against the value column
  \node[anchor=east, font=\fsSmall\selectfont, color=navy] at ({#1+\rowLabelW-0.15},{\ry}) {#4~#5};
  % R1 value sits immediately left of the light dot, mirroring the R2 value at
  % the dark dot, so each number touches its own end of the line. Safe even when
  % the arrow is short (CUHK03 A3): the two labels flank the pair outward.
  \node[anchor=east, font=\fsSmall\selectfont, color=muted] at ({\rxone-0.18},{\ry}) {#8};
  % column 3: the dumbbell
  \draw[navy, line width=1.7pt, -{Latex[length=2.4mm,width=1.8mm]}] (\rxone,\ry) -- (\rxtwo,\ry);
  \draw[fill=navyramp2, draw=navy, line width=0.9pt] (\rxone,\ry) circle (0.13);
  \draw[fill=navyramp5, draw=navy, line width=0.9pt] (\rxtwo,\ry) circle (0.15);
  % column 4: R2 value, left-aligned just past the dark dot, bold
  \node[anchor=west, font=\fsSmall\selectfont, color=navy] at ({\rxtwo+0.22},{\ry}) {\textbf{#9}};
}
