% Heatmap replacement for the old §5 line chart (2026-08-17 chart redesign).
% Rationale: A0/A3/A4 converge to within 0.04 after R2 (three lines overlap into
% one band) and A2/A0-Graph are single R4-only points forced into line-chart
% grammar. A heatmap removes both problems -- convergence just means adjacent
% cells share a shade, and an R4-only attacker is simply a row with three blank
% cells, which is a completely normal heatmap shape.
%
% Two panels, rows=attackers, columns=release stages, cell shade=magnitude
% (sequential navy ramp, scaled independently per metric), exact value printed
% in every present cell. Attacker A1 (omitted from the old line-chart version)
% is included here: a heatmap grid is free to add a row, and A1 already appears
% in the §7 attacker ladder, so leaving it out here would look inconsistent.
%
% Data source: paper tab:exp_means (Compositional_Non_Face_..._Vision_Releases.tex).
% Cross-checked value-for-value against the paper table; see BUILD_NOTES.md.
% Colours: navyramp1..5 (navyramp5 == navy) and heatempty, all native CMYK,
% defined once in the main .tex preamble. No RGB, no new hue.
%
% Shade buckets (1=lightest..5=navy, 0=no value) were assigned by linear
% min-max normalization of each metric's *present* values only (P_guess:
% min=.1600 @A1/R1, max=.7529 @A0/R3; vRPI2: min=1.6561 @A1/R1, max=6.3572
% @A2/R4), so shade is comparable within a panel. Text colour flips to white
% starting at bucket 3 for legibility on the darker fills (checked by render).

% ---- reusable per-cell drawer: #1 xOffset #2 row #3 col #4 bucket(0-5) #5 text ----

% ---- reusable panel scaffold: #1 xOffset #2 title ----
\newcommand{\hpanel}[2]{%
  \node[anchor=north, font=\fsSmall\bfseries\selectfont, color=navy] at (#1+0.5*(\labelW+4*\cellW),0) {#2};
  \foreach \c/\name in {0/R1,1/R2,2/R3,3/R4} {
    \node[font=\fsSmall\selectfont, color=navy] at ({#1+\labelW+(\c+0.5)*\cellW},{-0.62-0.5*\headerH}) {\name};
  }
  \foreach \r/\name in {0/A0,1/A1,2/A3,3/A4,4/A2,5/A0-Graph} {
    \node[anchor=east, font=\fsSmall\selectfont, color=navy] at ({#1+\labelW-0.12},{\gridTop-(\r+0.5)*\cellH}) {\name};
  }
}
